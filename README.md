## 📖 简介

AI 正在深刻改变写作的方式。无论是网络小说作者、自媒体创作者、学术研究人员，还是日常办公文档撰写者，都能够在 AI 的辅助下大幅提升写作效率与质量。

然而，市面上的 AI 写作工具种类繁多、良莠不齐——有的擅长长篇叙事，有的专攻公文格式，有的则聚焦于灵感激发。**选对工具，事半功倍。**

本列表旨在为中文写作者提供一份**高质量、有温度、持续更新**的工具索引。我们不仅收录工具，更希望帮你理解每款工具的核心定位和适用场景。

### 🎯 收录标准

- **中文友好**：对中文写作有较好的支持，或专门面向中文用户设计
- **实际可用**：有明确的产品形态（Web/App/API），非纯概念
- **写作核心**：以写作辅助为主要功能，而非泛化的聊天机器人
- **持续维护**：项目保持活跃，或产品稳定运行

2. 创建你的特性分支：`git checkout -b feature/add-new-tool`
3. 提交你的修改：`git commit -m 'Add: 某某写作工具'`
4. 推送到分支：`git push origin feature/add-new-tool`
5. 发起 **Pull Request** 并等待审核

### 提交规范

新增工具请遵循以下格式（在对应分类下添加）：

```markdown
### 工具名称 — 一句话描述

**一句话**：[不超过20字的精准描述]

| 项目 | 内容 |
|------|------|
| **官网** | [url] |
| **核心功能** | ✅ 功能1<br>✅ 功能2<br>✅ 功能3 |
| **适用场景** | 场景描述 |
| **免费额度** | 免费额度说明 |
| **平台** | Web / App / 桌面 |

> 💡 **点评**：[客观中肯的使用评价，50-100字]
```

**注意事项：**

- 🚫 **不接受纯广告推广**：提交的工具必须是真实可用、有一定用户基础的产品
- ✅ **客观描述**：功能描述需实事求是，不夸大不贬低
- 📝 **信息准确**：官网链接、价格、免费额度需与实际情况一致
- 🗣️ **中文优先**：工具需对中文写作有较好支持
- ❤️ **一人一票**：同类工具如已收录，新提交需说明差异化优势

**Issue 提交：**

如果你发现：
- 信息过时或错误
- 某工具已下线
- 有新的分类建议
- 其他任何改进意见

欢迎提交 [Issue](https://github.com/awesome-ai-writing-tools/awesome-ai-writing-tools/issues)！
